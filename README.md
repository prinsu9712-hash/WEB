# JRK Electrician Website

Premium service-booking website for **JRK Electrician** (`jrkelectrician.in`) built with React, Vite, Tailwind CSS, Framer Motion, React Icons, Swiper, and a lightbox gallery.

## Business details

- **Business:** JRK Electrician
- **Phone:** +91 94268 07286
- **Email:** jrkelectrician@gmail.com
- **Primary CTA:** Book on WhatsApp
- **Secondary CTA:** Call Now
- **Service area:** Gujarat, India

## Download everything

If you want a single downloadable file for the full project, run:

```bash
npm run download
```

This creates `jrk-electrician-website.zip` and excludes `node_modules`, `dist`, logs, and `.git` history.

You can also download the repository from GitHub as a ZIP after this branch is pushed.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```
